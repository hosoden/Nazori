# なぞりあそび

幼児が指やApple Pencilで、ひらがなを楽しくなぞるためのWebサイトです。

## ローカル起動

```bash
npm install
npm run dev -- --host 0.0.0.0
```

PCでは表示されたURLを開きます。iPad Safariでは、MacとiPadを同じWi-Fiに接続し、MacのIPアドレスを使って`http://<MacのIP>:5173`を開きます。

## ビルド確認

```bash
npm run build
```
